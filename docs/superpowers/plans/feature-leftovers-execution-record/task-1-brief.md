## Task 1: `nx migrate` 22.7.6 → 23.0.1

icore's root `nx`/`@nx/*` are pinned at `22.7.6`. crawler-nx (generated from this repo, then independently migrated by the user) is on `23.0.1`. Every day icore stays behind, the next scaffold diverges further from what users actually run. This task is foundational — Task 2 depends on the webpack-cli version this migration may pull in transitively.

**Files:**
- Modify: `package.json` (root) — `nx`/`@nx/*` versions
- Create: `migrations.json` (generated by `nx migrate`, deleted after migrations are run)
- Modify: any files nx's generated migrations touch (cannot be known ahead of time — inspect `migrations.json` before running)

**Interfaces:** None — this is a tooling upgrade, not application code.

- [ ] **Step 1: Fetch the migration set**

```bash
yarn nx migrate 23.0.1
```

Expected: `package.json` gets `nx`/`@nx/*` bumped to `23.0.1`, and a `migrations.json` file appears in the repo root listing any codemods to run.

- [ ] **Step 2: Install the new versions**

```bash
yarn install
```

Expected: exits 0, lockfile updated.

- [ ] **Step 3: Inspect the migration list before running it**

```bash
cat migrations.json
```

Read every entry. If any migration touches `apps/api/project.json`, `apps/microservices/*/project.json`, or webpack config, note it — it may overlap with Task 2 below. If a migration looks unrelated to this workspace (e.g. targets a plugin not in use), it's still safe to run — nx skips migrations that don't apply.

- [ ] **Step 4: Run the migrations**

```bash
yarn nx migrate --run-migrations
```

Expected: exits 0. `migrations.json` is deleted automatically on success.

- [ ] **Step 5: Full affected build/lint/test**

```bash
yarn nx run-many -t lint test build
```

Expected: all green. If `apps/microservices/{auth,notes,upload}` builds fail with a webpack-cli error mentioning `--node-env`, that's Task 2's bug surfacing — leave it failing and proceed to Task 2 (do not hand-patch here).

- [ ] **Step 6: Record the webpack-cli version that landed**

```bash
grep '"webpack-cli"' package.json
```

Write down the resolved version — Task 2 needs to know whether it's still `^5.1.4` (bug won't reproduce, skip the version-bump half of Task 2) or something newer (bug reproduces, do the full Task 2).

- [ ] **Step 7: Commit**

```bash
git add package.json yarn.lock
git commit -m "chore: nx migrate 22.7.6 -> 23.0.1"
```

(Add any files touched by migrations from Step 4 to this commit too.)
